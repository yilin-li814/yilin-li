# FX Hedging

Hedging a foreign-currency receivable for a U.S. firm: comparing a forward,
a money-market hedge, and a put option on the currency.

Scenario: beef-processor, a EUR 3,900,000 receivable due in 91 days.

## Files
- `README.md`: this file
- `spec.md`: model specification (Stage 2)
- `model.xlsx`: the hedging workbook (Stages 3–4)

The executive brief lives in `docs/briefs/`; the decision memo will live in `docs/decisions/`.
