# FX Hedging

Hedging a foreign-currency receivable for a U.S. firm: comparing no hedge, a forward,
a money-market hedge, and a put option on the currency.

Scenario: beef-processor, a EUR 3,900,000 receivable due in 91 days.

## Files
- `README.md`: this file
- `spec.md`: model specification (Stage 2), the named-range contract, calculation flow, and validation rules
- `model.xlsx`: the hedging workbook (Stages 3–4)
